# ASKLMS Landing Page

This is a Next.js-based landing page for ASKLMS, built with TypeScript, Tailwind CSS, and various UI components.

## Features

- Responsive design
- Modern UI with Radix UI components
- Contact form integration
- Technology showcase
- Admin features

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

To build for production:
```bash
npm run build
npm start
```

## Lint

Run ESLint:
```bash
npm run lint
```

## Technologies Used

- Next.js
- Django
- Tailwind CSS
- Radix UI
- Framer Motion
